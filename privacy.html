プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-10-30

本ポリシーは、個人用ツール「motivation-jp-subtitles」（以下「本アプリ」）における情報の取り扱いを定めるものです。

This policy describes how the personal tool "motivation-jp-subtitles" (the "App") handles information.

1. 取得する情報 / Information we access

本アプリは、Google OAuth を通じて、運営者自身の YouTube チャンネルに動画をアップロードする権限（https://www.googleapis.com/auth/youtube.upload）のみを取得します。チャンネルの動画一覧、視聴履歴、コメント、連絡先などその他の Google ユーザーデータにはアクセスしません。

Through Google OAuth, the App requests only permission to upload videos to the operator's own YouTube channel (youtube.upload). It does not access any other Google user data such as video lists, watch history, comments or contacts.

2. 利用目的 / How we use it

取得した権限は、日本語字幕を付けた動画を運営者のチャンネルへ投稿する目的にのみ使用します。

The permission is used solely to upload subtitled videos to the operator's channel.

3. 保存と管理 / Storage

認証に必要なトークンは、運営者のみがアクセスできる環境（GitHub Actions の暗号化されたシークレット）に保存します。本アプリは利用者の個人情報を収集・保存しません。

The authorization token is stored only in an environment accessible to the operator (encrypted GitHub Actions secrets). The App does not collect or store personal information about users.

4. 第三者への提供 / Sharing

Google ユーザーデータを第三者に販売・提供・共有することはありません。字幕作成のため、動画の文字起こしテキストを翻訳 AI サービス（Google Gemini API、Anthropic Claude API）に送信しますが、これに Google ユーザーデータは含まれません。

We do not sell, transfer or share Google user data with third parties. Transcribed speech text is sent to AI translation services (Google Gemini API, Anthropic Claude API) to create subtitles; this does not include any Google user data.

5. Google API サービスのユーザーデータに関するポリシー / Google API Services User Data Policy

本アプリによる Google API から取得した情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. 権限の取り消し / Revoking access

本アプリへのアクセス権は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

Access can be revoked at any time from your Google Account's third-party apps page.
